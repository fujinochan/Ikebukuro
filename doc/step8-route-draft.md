# Step 8 配置・攻略経路の下案

作成日: 2026-10-17。プロジェクト内の既存データだけを調査した下案。UEでの配置・移動・戦闘検証前であり、座標と構成は実測に合わせて変更する。

## 構成

- 最初の地上2体で、照準と手裏剣、単発ジャンプからの踏みつけを試す。
- 低い屋上、中層の屋上、地上の終盤へつなぐ計8体の経路を作る。地形に沿った道順と推奨順を表示するが、撃破順は強制しない。
- 中層への3段ジャンプを近道にし、苦手な人には単発ジャンプで上がれる補助足場を用意する。
- 黒い主人公の輪郭と、敵・補助足場の見つけやすさを調整する。
- 外部素材を取得せず、ローカルで作る短い効果音と投射・命中・踏みつけ・ジャンプ成功の演出を加える。

## 確認と調整

1. 各敵の足場と巡回領域を確認し、8体全員の準備が完了してから開始できるようにする。
2. 実際の入力で道路移動、屋上へのジャンプ、補助足場での着地、両方の撃破を確認する。単純な直線距離だけで到達可能と判断しない。
3. 8体の撃破・勝利・敗北・ポーズ・リトライを確認する。既存の3体用練習マップも残す。
4. 3〜5分の初見クリアを目標に、距離、探す時間、ジャンプの試行回数を記録して調整する。自動検証と初見の人による試遊は区別し、未実施の試遊を完了と扱わない。
