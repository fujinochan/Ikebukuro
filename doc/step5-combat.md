# Step 5 — 忍者の外見と踏みつけ・手裏剣

実施日: 2026-10-16

状態: Step 5完了。戦闘の実装、外見と照準の目視確認、練習・池袋マップでの実行検証を実施した。

後続変更: [Step 6](step6-encounters.md)で池袋の配置を巡回する地上2体・屋上1体に更新した。以下の「池袋に静止した1体」はStep 5時点の記録。`L_NinjaCombat` の静止した3体は継続して利用できる。

## 試す場所と操作

起動マップは引き続き `L_Ikebukuro`。開始地点から東へ約24m、Step 4で確認した道路上に赤忍者を1体配置した。`Content/Ninja/Maps/L_NinjaCombat` には、すぐ戦闘を試せる静止した赤忍者を3体置いた。

| 操作 | 入力 |
| --- | --- |
| 移動・視点 | WASD・マウス |
| 走る | Shift |
| ジャンプ | Space。離して頂点付近で押し直すと最大3段 |
| 手裏剣 | 左クリックまたはF。押すごとに1枚 |
| 踏みつけ | 敵より上から下降して頭上に当たる |
| 安全地点へ戻る | R |

照準は画面中央。主人公が狙う敵を隠しにくいよう、Ninja用カメラを右90cm・上60cmへずらした。位置は `CameraShoulderOffset` で調整できる。敵を全て復活させたい場合はPlayを終了して再開する。Rは移動の復帰操作であり、敵や撃破数はリセットしない。

## 外見

既存のQuinnスケルトンとアニメーションを継続使用する。主人公は黒、敵は赤のつやを抑えたマテリアル。頭のボーンに頭巾・覆面・目、腰のボーンに黒帯を取り付けた。部品はUE標準の球・立方体・円柱による試作で、アニメーションに追従する。外見の部品には衝突を持たせない。

`NinjaAppearance.*` と `Content/Ninja/Materials/M_Ninja*` が外見を担当する。マテリアルのスケルタルメッシュ使用フラグを保存し、実行時に参照する5種とUE標準の `BasicShapes` を `DirectoriesToAlwaysCook` に指定した。新しい外部素材・コードの取得は行っていない。

## 戦闘のルール

`RedNinja::TryDefeat` に撃破を集約する。死亡フラグを先に立てて衝突を無効にし、主人公の撃破数を1回だけ増やす。同じ敵への追加命中は無視する。Step 5の敵は静止し、巡回・追跡はStep 6で実装する。

踏みつけは、下降速度が50cm/sを超え、上向きの衝突面で、敵カプセル上端から25cm以内に当たり、直前の主人公の足も上端付近より高い場合に成立する。上昇中、側面、下面の接触は撃破にならない。成功時に上向き650cm/sで跳ね返す。ジャンプ段数と元のジャンプの追加入力受付時刻は補充せず、地面への着地で段数をリセットする。死亡した敵との遅れて届く着地通知でも、空中で段数を補充しない。

手裏剣はカメラ中央のトレースで狙う点を決め、右手からその方向へ直進する。胸から手元への経路も球Sweepで調べ、手が壁へ入り込んでいる場合の通り抜けを防ぐ。

| 項目 | 初期値 |
| --- | --- |
| 手裏剣の速度 | 5,000cm/s（50m/s） |
| 衝突球の半径 | 8cm |
| 発射間隔 | 0.3秒 |
| 射程 | 約60m。距離チェックの1フレーム分の差を許す |
| 寿命 | 最大2秒 |
| 重力・追尾・跳ね返り | 無効 |

`ProjectileMovementComponent` のSweepで最初の敵・壁・地面に当たると消える。所有する主人公は移動判定から除外する。走行中・空中でも投げられる。投射専用の腕アニメーションや命中エフェクトはまだ付けていない。

## 体力と復帰

体力は3。生きた敵との踏みつけ以外の接触で1減り、1秒間の無敵時間と小さな反動を与える。落下では1減らして安全地点へ戻る。範囲外からの復帰とRには体力減少を付けない。

この戦闘試作では体力0で安全地点へ戻り、体力を3に戻す。撃破した敵と撃破数は維持する。正式な敗北・残り時間・リトライ画面はStep 7以降で置き換える。復帰時には速度に加えて未処理の跳ね返り・ノックバックも取り消す。

HUDに体力、無敵時間、撃破数、照準、戦闘フィードバックを追加した。

## 再生成・検証

エディタを保存して終了し、プロジェクトルートで次を実行する。UE・MSVC・SDKと通常の設定・キャッシュへのアクセスはStep 5の承認範囲を使用する。

```powershell
& .\Tools\Editor\Build-Step1.ps1
& .\Tools\Editor\Setup-Step5.ps1
& .\Tools\Editor\Verify-Step5.ps1 -FPS 60 -RunName step5-recheck60
& .\Tools\Editor\Verify-Step5.ps1 -FPS 30 -RunName step5-recheck30
& .\Tools\Editor\Verify-Step5.ps1 -City -RunName step5-recheck-city
```

再生成は専用マテリアル、Ninja入力、Blueprint、戦闘マップ、池袋の静止敵を更新する。入力MappingContextはShift・F・左クリックを作り直す。再検証時には、既存レポートを上書きしない別のRunNameを指定する。

検証Actorはコマンドラインの専用フラグがある場合だけ動作する。通常プレイでは検証用の移動・攻撃・敵生成を行わない。HTTPを無効にしたローカル実行で、30Hz・60Hzの時間刻みを固定して確認する。これは実測描画fpsや完成版の性能を保証するテストではない。

### 確認した結果

| 確認 | 結果 |
| --- | --- |
| 戦闘10ケース | 30Hz・60Hzの両方でpassed |
| Fと左クリック | Enhanced Input経由で地上・空中の投射が成功 |
| 高速命中・最初の敵で停止 | 200m/sの検証弾が手前の敵で止まり、後ろの敵を倒さない |
| 壁の遮蔽 | カメラは敵を見通せても、手元からの弾は厚さ15cmの壁で停止 |
| 直進と消滅 | 水平投射の高さを維持し、射程で消滅 |
| 踏みつけ | 下降中の上面接触で撃破・跳ね返り。段数は地面着地まで維持 |
| 側面・上昇中の下面接触 | 敵を倒さず接触ダメージ。連続ダメージは無敵時間で拒否 |
| 落下・体力0 | 体力減少と安全地点への復帰が成功 |
| 同一フレームの撃破通知 | 踏みつけと手裏剣の両順序で、同じ敵の加算が1回 |
| 池袋の敵 | 固定道路上に着地し、照準に合わせたF入力で撃破 |
| 従来の移動 | 60HzのStep 3回帰検証がpassed |
| 池袋の足場・カメラ | 地面121地点、屋上3地点、表示切替、復帰3ケース、肩越しカメラ4方向がpassed |

同時命中の確認は、同一フレームで2種類の撃破通知を直接呼んで順序を逆転するテスト。実際の踏みつけ衝突と飛翔弾の命中は別ケースでも確認している。
