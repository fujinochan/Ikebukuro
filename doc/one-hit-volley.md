# 敵の移動拡大・3方向射撃・一撃敗北

作業日: 2026-10-17。配布版を作る前の追加ルールとして実装。以降の池袋ゲームでは、この記録が従来の体力3・非射撃の敵という仕様を置き換える。

## 現在のルール

| 項目 | 変更前 | 変更後 |
| --- | --- | --- |
| 巡回の目標距離 | 出現地点から最大4m | 最大8m。歩ける経路がある最も遠い候補へ移動 |
| 巡回領域の縦横 | 保存済みのHalfExtent | 各軸を2倍。実際の地面・屋上・橋の衝突を検査して歩ける場所に限定 |
| 巡回速度 | 1.6m/s | 3.2m/s |
| 追跡速度 | 4.2m/s | 8.4m/s |
| 帰還速度 | 2.6m/s | 5.2m/s |
| 遠距離攻撃 | なし | 黒忍者が100m以内なら2秒間隔で3発を同時投射 |
| 黒忍者 | 体力3と被弾後の無敵時間 | 一撃で敗北。HP表示なし |

狭い屋上では最大8mの巡回ができない場合がある。落下を防ぐため、繋がった安全な足場の範囲内で最も遠い地点を選ぶ。移動可能な床そのものを広げたり、屋上端を越えて歩かせたりはしない。

射撃の中央は黒忍者の現在位置を狙い、その正面と左右30度へ直進する。照準には高さも反映する。100mの判定は両者の3D距離。速度25m/s、最大射程120m、重力と追尾なし。ゲーム開始時は約2秒待って最初の射撃を行い、以降は各敵の2秒のクールダウンに従う。範囲外では新たに射撃しない。

敵の手裏剣は赤橙色に発光して見つけやすくした。建物や地面で止まり、壁際の射出位置も検査する。赤忍者同士は手裏剣を遮ったり被弾したりしない。射撃範囲と従来の近接追跡範囲は別で、近接追跡には引き続き歩ける経路が必要。

黒忍者は敵の手裏剣・敵との側面接触・落下や範囲外のペナルティで即敗北し、大爆発する。踏みつけ成功では被弾せず、従来どおり敵を倒して跳ね返る。Rによる任意の安全地点への復帰はペナルティなし。内部の既存Health参照は生存1／敗北0として維持し、ゲーム画面からHPの数値と無敵表示を除いた。

敵8体の全滅で勝利、約4分4秒の曲終了で敗北。ポーズでは敵の射撃と弾も停止する。勝敗確定時とリトライ時に両陣営の弾を消去し、リトライは射撃設定・カウンター・クールダウンと黒忍者を初期状態に戻す。勝敗が同じフレームなら従来どおり全滅による勝利を優先する。

## 実装

- `NinjaPatrolArea` に領域倍率2と目標半径800cmを追加。巡回候補を距離順に調べ、最初に経路が見つかった地点を採用して、拡大した領域での経路探索の重複を抑えた。グラフの点数上限に達する大きな練習領域でも両端を覆うように配置する。
- `RedNinja` の歩行速度を2倍にし、通常のAI Tickから `TryFireVolley` を呼ぶ。射撃と近接追跡の距離を分けた。
- `NinjaShuriken` を両陣営で共用。敵弾はPawnとのSweep Overlapで黒忍者だけを検出して敗北させ、WorldStatic等との衝突で停止する。`NinjaProjectile` オブジェクトチャンネルを新設し、弾同士の衝突を除外した。
- `NinjaCharacter`、HUD、`NinjaMatchDirector` のリトライ記録と関連する現行検証を一撃ルールへ更新。
- 地図や忍者のアセットを再生成せず、既存レベルにもコードと新規プロパティの初期値で反映する。Directorのない練習マップだけは撃破後に即復帰する練習用挙動を維持する。

既存のStep 9で承認されたUE・MSVC・SDKと通常の設定・キャッシュ等を使用。追加の外部ツール・素材・ダウンロード、Gitのリモート接続はない。

## 検証

UE Editor対象のビルド成功。100m射撃と衝突の専用検証は練習マップ30fpsと描画ありの池袋60fpsの固定物理時間で各14項目成功した。固定fpsは性能値ではない。

- 100.01mで撃たず、ちょうど100mで3発を出す。
- 角度が-30／0／+30度で、重力・追尾がない。
- 通常のAI Tickから2秒間隔で発射し、連打でクールダウンを回避できない。
- 範囲外に離れると新たな射撃が止まり、ポーズ中は弾も停止する。
- 弾が赤い仲間を通過し、15cm厚の壁で停止する。射出位置が壁を越える場合も貫通しない。
- 実際に飛んだ敵弾1発で敗北・大爆発が1回発生し、終了後の追加ダメージを拒否する。
- 両陣営の弾を終了時に消し、リトライで射程・間隔・カウンター・生存状態を復元する。

距離・射撃・衝突の試験は、敵の移動を止め、黒忍者を指定位置へ配置して切り分ける。既存練習壁の影響を避ける衝突用の壁は上空に配置し、池袋版では範囲境界試験中のみエリア復帰を止める。通常の移動や通しプレイを再現する試験とは区別する。

別途、拡張した池袋の8体を10秒巡回させて安全復帰0回、補助経路46回の着地と地上から中層屋上への3段ジャンプが成功。射撃と接触はこの移動試験だけ無効化した。巡回グラフは各12〜285ノードに拡大している。

一撃敗北へ更新した池袋のゲーム進行25項目、巨大爆発10項目、自動カメラ14項目、実際のM4Aデコードを伴うBGMの12項目も成功。BGMの終了試験は末尾にシークして実際の終了イベントを確認する。

レポート: [射撃30fps](validation/volley-30.json)、[池袋射撃](validation/volley-city.json)、[巡回・屋上経路](validation/volley-route.json)、[ゲーム進行](validation/volley-match.json)、[BGM](validation/volley-music.json)、[爆発](validation/volley-explosion.json)、[カメラ](validation/volley-camera.json)。

確認画像: [赤忍者の3方向射撃](validation/volley-fan.png)、[一撃被弾の大爆発](validation/volley-one-hit.png)。撮影時は従来の300秒タイマーを明示指定した検証モードを使用。通常プレイはBGMの長さに従う。

従来のStep 5〜6に記録した体力3・非致死被弾・無敵時間の試験は旧仕様。現行の被弾ルールは本検証を参照する。Step 9の性能比較も今回の敵拡張前の記録であり、この射撃・巡回拡張後の性能を保証する値ではない。初見クリア難易度と実際の通し試遊は未確認。
