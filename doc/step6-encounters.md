# Step 6 — 巡回・追跡と地上／屋上の遭遇

実装日: 2026-10-16。UE 5.8.2、既存のプロジェクト内素材のみを使用。

後続変更: [Step 6.5](step6_5-textures.md)で建物をテクスチャ付きLOD2に切り替え、固定足場を再生成した。屋上の敵と巡回領域の基準高は約30cm上がり、1671.19cmになった。以下の配置値はStep 6時点の記録。

後続変更: [Step 7](step7-match-flow.md)で通常の池袋Playに開始画面・300秒・勝敗・リトライを追加した。池袋の試合では体力0が敗北になる。以下の自動回復や自由な練習はStep 6時点の仕様で、既存の練習マップ・専用回帰検証では引き続き使う。

## 遊び方

起動マップは引き続き `/Game/Ninja/Maps/L_Ikebukuro`。赤忍者を地上2体・低い屋上1体に配置した。地上の敵は開始地点の道を進んだ先、屋上の敵は開始地点から西へ約40mの建物にいる。屋上の高さは開始地点の路面から約7m。3段ジャンプで近づき、下降中に踏むか、照準を合わせて手裏剣を当てる。

練習用の `/Game/Ninja/Maps/L_NinjaEncounter` には、地上2体、8mの屋上に1体、迂回を試せる壁を配置した。旧 `L_NinjaCombat` の停止した敵による練習も残している。

| 操作 | 入力 |
| --- | --- |
| 移動／視点 | WASD／マウス |
| 走る | Shift |
| ジャンプ／頂点付近で次の段 | Space |
| 直進する手裏剣 | 左クリックまたはF |
| 安全な路面へ戻る | R |

画面に残敵数と位置のヒント、見えている敵の頭上に `STREET / Patrol`、`ROOF / Chase` などの状態を表示する。頭上表示は壁に隠れる敵を透視しない。敵の方向マーカー、300秒タイマー、勝敗とリトライはStep 7で追加する。現時点の体力0はStep 5と同じく、体力を回復して復帰する仮仕様。

## 行動

`Waiting → Patrol → Chase → Attack → Return` を基本とし、経路が塞がった場合は `Blocked` で停止して再試行する。撃破後は `Defeated` となり移動・攻撃・衝突を止める。

| 項目 | 通常時の値 |
| --- | --- |
| 巡回／追跡／帰還速度 | 1.6／4.2／2.6 m/s |
| 巡回地点 | 持ち場から2.5〜4mの到達可能な地点を左右交互に選ぶ |
| 発見距離 | 10m。追跡中は15mまで継続 |
| 主人公の追跡限界 | 持ち場から18m、足元の高低差1m未満、同じ歩行領域内 |
| 攻撃 | 1m以内で壁に遮られていないとき。1.25秒ごとに接触ダメージを試みる |
| 再経路探索／停止後の再試行 | 0.6秒 |
| 帰還直後の再発見待ち | 1秒 |

発見は距離による簡単な方式。壁の向こうでも、同じ領域内で経路があれば迂回して追う。攻撃には遮蔽判定を使う。既存の側面接触ダメージと1秒の無敵時間も有効。

主人公が別の屋上・地面に移った場合や、行動範囲外に出た場合は持ち場へ歩いて戻る。屋上間のジャンプや落下追跡はしない。外部から位置をずらすなどして足場を失った場合だけ、検証済みの元の持ち場に復帰する。

既存 `Variant_Combat/AI/CombatAIController.cpp` と `CombatStateTreeUtility.cpp` のStateTreeによる状態管理・地上移動を参考にした。この3体の試作では、状態遷移を追いやすいC++の列挙型と経路探索で実装し、StateTreeアセット自体は組み込んでいない。

## 固定した足場上の経路

`ANinjaPatrolArea` が、Step 4で保存した `WorldStatic` の足場コリジョンに対して1.5m間隔の歩行グラフを作る。描画用Cesiumタイルや、主人公・他の敵を床として扱わない。最初の敵が着地し、開始から0.5秒以上経過してから構築し、同じ領域の敵で共有する。

- 中心と前後左右50cmの床、35cm以内の段差、床法線Zが0.85以上であることを確認する。
- 半径43cm・半高88cmのカプセルで頭上と移動経路を確認する。移動区間の床を50cm間隔で確認する。
- 安全な上下左右4方向の辺に対して幅優先探索し、移動直前にも足元と経路を再確認する。
- 屋上のグラフは指定した高さ±1mの足場に限定する。別の階や下の路面へ接続しない。

| マップ／領域 | 中心座標cm | 指定する幅×奥行き |
| --- | --- | --- |
| 池袋・地上 | 約(13718, -5055, 919) | 36m × 12m |
| 池袋・屋上 | (8345.25, -6637.38, 1641.19) | 15m × 15m |
| 練習・地上 | (1800, 800, 0) | 60m × 40m |
| 練習・屋上 | (700, -1800, 800) | 16m × 16m |

指定矩形の全体を歩けるとは仮定せず、実際の形状と安全余白を満たす部分だけを採用する。池袋の屋上は不整形で、有効な点は28個。地上は161個、練習マップは地上1005個・屋上100個となった。全市街を移動するNavMeshではなく、この小区域の3体を対象にした実装。

## 再生成と検証

UEエディタを保存して終了し、プロジェクトのルートで実行する。既存レポートの上書きは拒否するため、再実行時は別の `RunName` を指定する。

```powershell
.\Tools\Editor\Build-Step1.ps1
.\Tools\Editor\Setup-Step6.ps1
.\Tools\Editor\Verify-Step6.ps1 -FPS 60 -RunName step6-encounter-60
.\Tools\Editor\Verify-Step6.ps1 -City -FPS 60 -RunName step6-city-60
.\Tools\Editor\Verify-Step6.ps1 -FPS 30 -RunName step6-encounter-30
.\Tools\Editor\Verify-Step6.ps1 -City -FPS 30 -RunName step6-city-30
.\Tools\Editor\Verify-Step5.ps1 -RunName step6-combat-regression
.\Tools\Editor\Verify-Step4.ps1 -RunName step6-city-regression
```

`ANinjaEncounterCheck` は `-NinjaEncounterCheck` がある実行だけで有効になる。通常のPlayでは主人公や敵を検証のために移動させない。

検証は3体の連続12秒の巡回、壁を避ける追跡、攻撃、見失った後の帰還、屋上外の到達不能地点、強制的な位置ずれからの復帰を確認する。その後、地上と屋上で踏みつけ・手裏剣の両方、実際のSpace入力による3段ジャンプと着地時の回復を確認する。撃破方法を個別に確認する間は敵を停止し、4通りの撃破を試すため検証時だけ屋上に静止した敵を1体追加する。射撃前のカメラ調整中に接触で突き落とされる条件を分離した。通常マップの配置数はAIが動く3体。

通常移動中の安全復帰は0回、強制的に屋上からずらした場合は1回を要求する。旧Step 4の床・走行・カメラ検証では新しい敵の衝突と表示を無効化し、足場を単独で確認する。Step 6の遭遇検証では敵のAI・衝突を有効にしている。

固定時間刻み30／60Hzでの結果は判定と移動の安定性を確認するもので、実際の描画が30／60fpsを維持するという性能測定ではない。性能測定はStep 9、配布ビルドの更新は後続工程で行う。
